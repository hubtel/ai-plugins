# Application controls

- **Identity lifecycle:** Review registration, invitations, password storage, reset, account recovery, account linking, email and phone changes, account suspension, and staff impersonation. Check MFA and passkey enrollment, replacement, and recovery. Review WebAuthn challenge binding and expiry, origin and relying party validation, and required user verification. Check OTP attempt limits, lifetime, and single use. For OAuth/OIDC check issuer, audience, redirect validation, state, nonce, PKCE, and account mapping as applicable.
- **Session lifecycle:** Trace creation, regeneration after login or privilege change, renewal, logout, expiry, and revocation after credential or role changes. Check cookie attributes and scope, server-side session lifetime, refresh rotation, JWT signature and claims, signing key rotation, and where tokens appear in browser storage, SSR payloads, URLs, logs, and traces.
- **Authorization and tenancy:** Require server-side checks for action, object, tenant, and field access. Trace identifiers into persistence filters and updates. Cover RBAC, administrative and service identities, exports, bulk APIs, file access, queues, and cache keys. Review trust in forwarded headers and identity propagated from a BFF.
- **Browser and input:** Review CSRF protection on state changes, CORS credential policies, output encoding, unsafe HTML, CSP, redirects, untrusted URLs, validation and mass assignment. Trace untrusted data into database queries, command execution, templates, file paths, parsers, outbound requests, and uploads. Check publicly exposed server configuration and frontend bundles.
- **Data and secrets:** Review TLS configuration, key and secret handling, least-privilege access, storage and retention, redaction, backups, exports, and audit logs. Check environment separation and service-to-service authentication.
- **Operations:** Review lockfiles and component advisories when available, CI/CD permissions, build and release provenance, dependency and secret scanning, IAM, debug settings, shared caching, rate limiting, resource limits, error exposure, and alerts for sensitive actions. Record runtime controls that require separate evidence.
